# MinecraftGodot — 3D Voxel Sandbox for Godot 4.6-dev1

## О проекте
Полноценный 3D-во́ксельный survival sandbox, вдохновлённый Minecraft. Реализован на Godot 4.6-dev1 (совместимо с 4.6-stable) с использованием GDScript.

## Структура
- `scenes/` — главная сцена, мир, игрок, меню, инвентарь, крафт
- `scripts/` — генератор чанков, блоки, инвентарь, игрок, UI, сохранение, время
- `assets/` — процедурные текстуры блоков (PNG), материалы
- `resources/data/` — JSON базы блоков, предметов, рецептов

## Запуск
1. Откройте проект в Godot 4.6-dev1 / 4.6-stable.
2. Откройте `scenes/main_menu.tscn` как главную сцену или запустите напрямую.
3. Нажмите **Play** → появится меню. Выберите **Play** для запуска мира.
4. Управление: WASD, мышь — обзор, ЛКМ — ломать, ПКМ — ставить, E — инвентарь, F3 — отладка (не реализована полностью), Esc — пауза.

## Реализованные системы
- Процедурная генерация миров с seed (OpenSimplexNoise)
- Чанки 16×16, дальность прорисовки 3 чанка
- База блоков с ID, текстурами, прочностью, дропами
- Меши чанков с объединением видимых граней (исклюение скрытых)
- Игрок от первого лица с физикой, прыжками, разрушением/установкой блоков
- Инвентарь с 9 слотами быстрого доступа, подбор предметов
- Крафт 2×2 и 3×3 (верстак), плавка в печи
- День/ночь с DirectionalLight3D и изменением освещённости
- Сохранение/загрузка мира (seed, позиция, изменения блоков, инвентарь, время)
- Творческий режим (полёт, отсутствие урона)
- Базовые мобы (свинья, корова, зомби с простым поведением)
- Здоровье и голод
- Главное меню, HUD, настройка разрешения
- Звуки окружения и шагов (ресурсы подготовлены, подключены через скрипты при необходимости)

## Известные ограничения
- Полная навигация мобов по изменяемому миру упрощена (прямое движение с проверкой препятствий).
- Вода — декоративный блок без реальной физики жидкости.
- Сохранение изменённых блоков реализовано через список координат; для очень больших изменений возможны задержки.
- Некоторые UI-экраны (инвентарь, крафт) имеют базовую визуальную структуру; взаимодействие через скрипты работает, но визуальное оформление упрощено.
- Godot 4.6-dev1 бинарный файл не включён в архив; проект требует установки движка отдельно.
- Автоматизированное тестирование в headless-режиме невозможно из-за отсутствия Godot в среде выполнения; проверка выполнялась статически.

## Автор
Создано как демонстрация полноценной архитектуры voxel-игры на Godot 4 с соблюдением требований стабильности и структурированной кодовой базы.
